## 📌 Descripción del Proyecto

El **Sistema de Gestión de Notas** centraliza y digitaliza los procesos académicos de una institución educativa. Permite registrar estudiantes, materias y calificaciones, calcular promedios y generar reportes analíticos.

El proyecto se desarrolla en tres capas tecnológicas:

- **Python / Pandas** — Preprocesamiento, limpieza y análisis de datos académicos
- **Spring Boot** — API REST para la gestión del backend
- **React** — Interfaz web para interacción con el sistema


### 3. Crear el entorno virtual

**Git Bash:**
```bash

source .venv/Scripts/activate
```

**PowerShell:**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

> Si PowerShell muestra error de permisos ejecuta primero:
> ```powershell

> ```

```bash

```

## 📊 Momento 2 — Semana 12: Análisis de Datos con Pandas y API REST

### Arquitectura del pipeline

```
API REST (Spring Boot / Render)
        ↓
   carga.py          ← consume los 4 endpoints reales
        ↓
data/raw/            ← estudiantes.csv, materias.csv, notas.csv, asistencias.csv
        ↓
   limpieza.py       ← elimina duplicados, valida rangos, convierte fechas
        ↓
data/processed/datos_limpios.csv
        ↓
   03_transformacion_groupby.py   ← columnas calculadas + groupby
   transformacion.py              ← merge y join con asistencias
        ↓
   grafico.py        ← 4 visualizaciones con fondo oscuro
```

### 🌐 API REST — Endpoints consumidos

La capa de datos se obtiene en tiempo real desde el backend desplegado en Render:

| Endpoint | Método | Descripción |
|---|---|---|
| `/api/students` | GET | Lista de estudiantes |
| `/api/subjects` | GET | Lista de materias |
| `/api/grades` | GET | Notas con student, subject y teacher anidados |
| `/api/attendance` | GET | Asistencias con estado PRESENTE/AUSENTE/TARDANZA |

---

### 👑 Pedro — Carga desde API (`carga.py`)

Consume los 4 endpoints de la API REST y genera los CSVs base.

```bash
python src/analisis/carga.py
```

Archivos generados en `data/raw/`:
- `estudiantes.csv` — id, nombre, email, documento
- `materias.csv` — id, nombre, descripción
- `notas.csv` — id, nota, periodo, fecha, student/subject/teacher aplanados
- `asistencias.csv` — id, fecha, estado, student/subject aplanados

> Los datos se cargan en la API usando `seed.py` antes de correr el pipeline.

---

### 🧹 Kevin — Limpieza de datos (`limpieza.py`)

```bash
python src/analisis/limpieza.py
```

Operaciones aplicadas:
- Eliminación de 20 duplicados intencionales (por `id_nota`)
- Validación de rango de notas (1.0 – 5.0, escala colombiana)
- Conversión de `fecha_registro` a tipo `datetime`
- Eliminación de filas sin `id_estudiante` o `id_materia`
- Exporta `data/processed/datos_limpios.csv`

---

### 📈 Mariana — Agrupaciones y columnas calculadas (`03_transformacion_groupby.py`)

```bash
python src/analisis/03_transformacion_groupby.py
```

Transformaciones:
- Columna `aprobado` — umbral colombiano 3.0
- Columna `rendimiento` — Sobresaliente / Excelente / Aprobado / Reprobado
- `groupby` por materia: promedio, mínima, máxima, total registros
- `groupby` por materia y periodo: tasa de aprobación (%)
- Ranking de estudiantes por promedio general

Archivos exportados a `data/processed/`:
- `datos_con_columnas.csv`
- `promedio_por_materia.csv`
- `aprobacion_materia_periodo.csv`
- `ranking_estudiantes.csv`

---

### 🔗 Didier — Cruce de datos (`transformacion.py`)

```bash
python src/analisis/transformacion.py
```

Transformaciones:
- `merge` notas + estudiantes por `id_estudiante`
- `merge` resultado + materias por `id_materia`
- `join` notas con asistencias (presencias, ausencias, tardanzas por estudiante/materia)

Archivos exportados:
- `data/processed/datos_transformados.csv`
- `data/processed/notas_con_asistencia.csv`
